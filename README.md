**Swiftly** is a minimalist CRUD To-Do application built with Laravel. It focuses on simplicity: a single-table database design, clean UI, and a professional, ready-to-use deliverable package.

---

## ✨ Features

-   **Full CRUD Functionality:** Add, edit, view, and delete tasks seamlessly.
-   **Status Tracking:** Manage workflow with _Pending_ and _Completed_ states.
-   **Due Date Support:** Keep track of deadlines for every task.
-   **Modern UI:** Card-based layout with a focus on dark minimalism and neumorphic accents.
-   **Lightweight Design:** Optimized single-table database structure for maximum efficiency.

## 🛠 Tech Stack

-   **Framework:** Laravel 10+
-   **Language:** PHP 8.1+
-   **Database:** MySQL
-   **Frontend:** Bootstrap 5 & Custom CSS (Inter font)
